# Windows ISO Builder
A command-line utility (from UUP Dump) designed to automate the process of creating customized Windows installation media. 

## Usage
Just fork the repo and run the workflow in the `Actions` Tab to get the ISO. Feel free to tweak the `CustomAppsList.txt` and `ConvertConfig.ini`before usage.
